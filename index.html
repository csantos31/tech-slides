05 / 07

Design Decisions

DecisionWhy
Vanilla JS onlyNo React, no build step — open the HTML and present. Runs anywhere, even offline.
CSS custom propertiesOne :root block to theme the entire deck. Swap --accent and you have a new brand.
CSS Grid for layoutsMetric cards, before/after columns, responsive breakpoints — all declarative, no JS layout.
Separated CSS + JSHTML stays under 100 lines. Copy the HTML, keep the assets — instant new presentation.
fullscreenchange eventSyncs UI state regardless of how fullscreen exits (button, ESC, F key, browser API).
Themes via data-theme<html data-theme="light"> + CSS variables per palette; JS array controls cycle order and toolbar icon.
Gradient text on h1background-clip: text for visual impact without images or extra markup.
Architecture

tech-slides.css (theme + components + slide engine)
  + tech-slides.js (navigation + keyboard + fullscreen)
    + your-slides.html (pure content — no inline styles or scripts)
